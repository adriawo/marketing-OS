# Fluxo de Trabalho do Marketing OS

Este documento define o fluxo oficial de trabalho do Marketing OS, desde o recebimento de uma demanda até a entrega final e o registro dos aprendizados.

Todos os especialistas devem seguir este fluxo para garantir organização, qualidade, consistência e evolução contínua da Base de Conhecimento da agência.

---

# Visão Geral do Fluxo

Todo projeto deve seguir as seguintes etapas:

1. Recebimento da Demanda
2. Análise do Contexto
3. Planejamento
4. Execução
5. Revisão
6. Entrega
7. Registro de Aprendizados
8. Atualização da Base de Conhecimento

Nenhuma etapa deve ser ignorada, salvo quando houver autorização explícita do Diretor de Campanhas.

---

# 1. Recebimento da Demanda

Objetivo:

Compreender completamente o projeto antes de iniciar qualquer atividade.

Registrar:

- Cliente.
- Projeto.
- Objetivo.
- Público-alvo.
- Produtos ou serviços.
- Mercado.
- Concorrentes.
- Entregas esperadas.
- Restrições.
- Cronograma.
- Critérios de sucesso.

Todo briefing deve ser armazenado em:

```text
briefs/
```

---

# 2. Análise do Contexto

Antes de iniciar qualquer produção, consultar a Base de Conhecimento.

Sempre verificar, quando aplicável:

```text
knowledge/clients/
knowledge/products/
knowledge/industries/
knowledge/competitors/
knowledge/personas/
knowledge/campaigns/
knowledge/brand-assets/
knowledge/playbooks/
knowledge/lessons-learned/
```

Objetivos desta etapa:

- Compreender o histórico do cliente.
- Identificar campanhas anteriores.
- Reutilizar aprendizados.
- Evitar retrabalho.
- Identificar informações faltantes.
- Registrar premissas.

Caso existam informações insuficientes, solicitar complementação antes de prosseguir.

---

# 3. Planejamento

Definir:

- Objetivos.
- Especialistas envolvidos.
- Entregas.
- Dependências.
- Cronograma.
- Pontos de revisão.
- Critérios de aprovação.

Sempre que possível utilizar templates existentes em:

```text
templates/
```

---

# 4. Execução

Cada especialista executará apenas as atividades correspondentes à sua função.

Exemplos:

- Pesquisa.
- Planejamento Estratégico.
- Desenvolvimento de Campanhas.
- Copywriting.
- Desenvolvimento de Embalagens.
- Trade Marketing.
- Social Media.
- Google Ads.
- Meta Ads.
- Analytics.
- Apresentações.

Todos os arquivos produzidos devem ser armazenados na pasta correspondente dentro de:

```text
output/
```

---

# 5. Revisão

Antes da entrega, validar:

- Alinhamento com o briefing.
- Objetivos do projeto.
- Estratégia aprovada.
- Posicionamento da marca.
- Público-alvo.
- Dados utilizados.
- Fontes.
- Clareza.
- Qualidade da redação.
- Organização do documento.
- Padronização visual.
- Nome do arquivo.
- Premissas registradas.
- Pendências identificadas.

Nenhuma entrega deve ser considerada final sem revisão.

---

# 6. Entrega

Finalizar o material no formato solicitado.

Sempre organizar os arquivos utilizando os padrões definidos em:

```text
conventions.md
```

Quando aplicável, produzir versões para:

- PowerPoint
- Google Apresentações
- PDF
- Documento em Markdown

---

# 7. Registro de Aprendizados

Após concluir o projeto, registrar:

- O que funcionou.
- O que não funcionou.
- Decisões importantes.
- Problemas encontrados.
- Melhorias implementadas.
- Recomendações para projetos futuros.

Sempre atualizar:

```text
knowledge/lessons-learned/
```

---

# 8. Atualização da Base de Conhecimento

Sempre avaliar se o projeto gerou conhecimento reutilizável.

Quando necessário, atualizar:

```text
knowledge/clients/
knowledge/products/
knowledge/industries/
knowledge/competitors/
knowledge/personas/
knowledge/campaigns/
knowledge/brand-assets/
knowledge/playbooks/
knowledge/lessons-learned/
```

O objetivo é garantir que cada projeto fortaleça continuamente a inteligência da agência.

---

# Organização das Entregas

Os materiais devem ser armazenados conforme sua finalidade.

| Tipo de Entrega | Local |
|-----------------|-------|
| Campanhas | `output/campaigns/` |
| Pesquisas | `output/research/` |
| Planejamento Estratégico | `output/strategy/` |
| Copywriting | `output/copy/` |
| Embalagens | `output/packaging/` |
| Trade Marketing | `output/trade/` |
| Redes Sociais | `output/social/` |
| Analytics | `output/analytics/` |
| Relatórios | `output/reports/` |
| Apresentações | `output/presentations/` |
| Documentos de apoio | `output/documents/` |
| Logs | `output/logs/` |

---

# Critérios de Revisão

Toda entrega deve ser validada quanto a:

- Atendimento ao briefing.
- Clareza estratégica.
- Coerência.
- Precisão das informações.
- Adequação ao público-alvo.
- Alinhamento com a marca.
- Consistência das mensagens.
- Qualidade da redação.
- Fontes utilizadas.
- Organização dos arquivos.
- Padronização do documento.
- Confidencialidade das informações.

---

# Fluxo entre Especialistas

O Marketing OS trabalha de forma colaborativa.

Sempre que necessário, um especialista deve encaminhar sua entrega ao próximo especialista responsável.

Exemplo:

Diretor de Campanhas

↓

Especialista em Pesquisa

↓

Especialista em Planejamento Estratégico

↓

Diretor Criativo

↓

Especialista em Embalagens

↓

Especialista em Trade Marketing

↓

Especialista em Analytics

↓

Especialista em Apresentações

↓

Diretor de Campanhas

Cada especialista deve registrar:

- O que recebeu.
- O que produziu.
- Premissas adotadas.
- Pendências.
- Recomendações.

---

# Situações que Exigem Revisão Humana

Os especialistas devem interromper o fluxo e solicitar revisão quando houver:

- Briefing incompleto.
- Informações contraditórias.
- Falta de dados confiáveis.
- Alteração significativa do escopo.
- Solicitação de informações não verificáveis.
- Aprovações pendentes.
- Dúvidas regulatórias.
- Necessidade de decisão estratégica.

---

# Filosofia do Fluxo de Trabalho

O Marketing OS foi desenvolvido para funcionar como uma equipe integrada de especialistas.

Cada etapa do processo existe para garantir que as decisões sejam baseadas em informações confiáveis, que o conhecimento da agência seja continuamente ampliado e que todas as entregas mantenham um padrão elevado de qualidade.

Cada projeto deve deixar um legado para os próximos, fortalecendo a Base de Conhecimento e tornando a agência cada vez mais eficiente.
