# Base de Conhecimento de Campanhas

Este documento armazena informações estratégicas sobre campanhas já executadas.

Seu objetivo é registrar aprendizados, resultados, decisões estratégicas e boas práticas para que possam ser reutilizados em futuros projetos.

Sempre que uma campanha for concluída, este documento deve ser atualizado.
