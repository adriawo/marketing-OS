# Padrão das Entregas

Toda entrega produzida utilizando este Playbook deve:

- Estar alinhada ao briefing.
- Seguir os padrões da agência.
- Considerar o público-alvo.
- Ser específica para o cliente.
- Estar pronta para revisão.
- Utilizar apenas informações verificáveis.

# Filosofia dos Playbooks

Os Playbooks representam a experiência acumulada da agência.

Eles transformam conhecimento prático em processos padronizados, permitindo que equipes e agentes executem projetos com maior qualidade, consistência e previsibilidade.

Sempre que um projeto gerar um novo método ou uma melhoria significativa, avalie se esse conhecimento deve ser incorporado a um Playbook existente ou originar um novo Playbook.
