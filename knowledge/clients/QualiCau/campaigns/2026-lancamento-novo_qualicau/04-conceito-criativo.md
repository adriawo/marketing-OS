# O Grande Desafio

Os consumidores não compram apenas chocolate em pó.

Eles compram:

- um bolo para a família;
- um café da manhã especial;
- uma sobremesa para o fim de semana;
- uma receita saudável;
- um momento de prazer.

A QualiCau deve deixar de comunicar apenas porcentagens e passar a comunicar possibilidades.

---

# Big Idea

## Existe um QualiCau para cada receita.

Cada percentual possui uma função.

Cada receita possui um sabor.

Cada pessoa possui um jeito de cozinhar.

A QualiCau acompanha todos esses momentos.

---

# Conceito da Campanha

## O ingrediente certo faz toda a diferença.

Assim como cada receita pede um ingrediente específico, existe um QualiCau ideal para cada preparo.

A nova arquitetura da linha facilita essa escolha.

# Manifesto

A cozinha muda todos os dias.

Existem receitas rápidas.

Receitas especiais.

Momentos em família.

Momentos só seus.

Por isso criamos uma linha completa.

Uma linha que facilita sua escolha.

Uma linha que acompanha cada receita.

Porque cada preparo merece o sabor certo.

Existe um QualiCau para cada receita.
