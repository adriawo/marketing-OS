# Padrão Visual — Planejamento Editorial Social Media

## Identificação

**Empresa:** Engenho Comunicação e Design

**Tipo de documento:** Planejamento Editorial de Social Media

**Uso:** Documento de apresentação e aprovação de planejamento editorial para clientes.

Este padrão visual é específico para planejamentos editoriais de Social Media.

Não utilizar este padrão automaticamente para propostas comerciais, relatórios, briefings, apresentações ou outros tipos de documento.

---

- Papel: A4
- Orientação: Retrato
- Margem superior: 2,54 cm
- Margem inferior: 2,54 cm
- Margem esquerda: 2,54 cm
- Margem direita: 2,54 cm

# Identidade Visual

O documento deve seguir uma estética:

- limpa;
- editorial;
- profissional;
- contemporânea;
- minimalista;
- com bastante espaço em branco.

Evitar:

- excesso de elementos decorativos;
- excesso de cores;
- emojis como elementos estruturais;
- aparência de relatório técnico;
- excesso de caixas e elementos gráficos.

---

# Capa

A capa deve apresentar:

PLANEJAMENTO EDITORIAL SMM

Período

Cliente

Breve descrição do documento

Informações básicas:

- Marca
- Período
- Etapa

Utilizar imagem ou elemento visual de apoio somente quando houver material adequado.

A imagem deve funcionar como elemento editorial, sem comprometer a leitura.

---

# Cabeçalho e Rodapé

Utilizar a identificação visual da Engenho de forma discreta.

O logo deve manter proporção e boa área de respiro.

Não utilizar o logo em tamanho excessivo.

---

# Títulos

Utilizar títulos grandes e fortes para separar as principais seções.

Manter hierarquia consistente em todo o documento.

Não utilizar títulos decorativos diferentes para cada seção.

---

# Conteúdos

Cada proposta de conteúdo deve possuir destaque próprio.

Preferir:

- título forte;
- tabela organizada;
- informações objetivas;
- separação clara entre propostas.

Evitar transformar todas as propostas em uma única tabela extremamente extensa.

---

# Tabelas

Utilizar tabelas simples e funcionais.

Priorizar:

- leitura rápida;
- alinhamento consistente;
- bordas discretas;
- boa largura das colunas;
- espaçamento interno adequado.

Não utilizar tabelas excessivamente compactadas.

Quando uma tabela ficar muito extensa, dividir o conteúdo em blocos.

---

# Espaçamento

Manter bastante espaço entre:

- seções;
- títulos;
- blocos de conteúdo;
- tabelas;
- parágrafos.

Evitar páginas visualmente congestionadas.

Quando necessário, iniciar uma nova seção em nova página.

---

# Imagens

Quando utilizadas:

- manter boa resolução;
- preservar proporções;
- evitar distorções;
- utilizar imagens relacionadas ao conteúdo;
- priorizar função editorial sobre decoração.

---

# Linguagem Visual

O documento deve transmitir:

**Estratégia + clareza + organização + profissionalismo.**

O cliente deve conseguir compreender rapidamente:

1. qual é o direcionamento;
2. o que está sendo proposto;
3. por que cada conteúdo está sendo proposto;
4. quais conteúdos são prioritários;
5. o que precisa ser aprovado.

---

# Regra de Uso

Este padrão deve ser utilizado exclusivamente para:

**Planejamento Editorial de Social Media.**

Outros documentos devem utilizar seus próprios padrões visuais.
